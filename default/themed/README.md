# Theme templates

Templates render the active Ve OS palette for terminals, editors, desktop controls and supported AI apps. Display names use Ve OS; upstream author credits, protocol identifiers and stable integration filenames remain intact where apps use them as keys.

Hermes publishes the `ve` skin and accepts an existing `omarchy` selection during migration. Herdr and T3 Code publish `ve.json`; existing `omarchy.json` palettes continue to refresh for users who still select them. Other user-selected themes are preserved.
