# Ve OS manual

Start with [Welcome to Ve OS](01-welcome-to-omarchy.md), [Getting Started](02-getting-started.md), [Navigation](04-navigation.md) and [Hotkeys](07-hotkeys.md). The repository [chapter index](../README.md#ve-os-manual) lists the full manual.

Ve OS is a development fork of Omarchy. The desktop and its menus use Ve branding. The `omarchy` commands, package names, paths and plugin identifiers remain compatible with upstream. Applications such as Omawrite, Hype and Monologue belong to their original maintainers.

The English setup, update and Mac chapters describe this fork. Translated setup and platform chapters retain a labelled upstream reference until their Ve-specific guidance is translated. Upstream installation images, release channels, package servers, signing keys and community links remain upstream resources; this fork does not publish a separate Ve ISO or package distribution. Screenshots inherited from upstream illustrate workflows and may show the original artwork.
